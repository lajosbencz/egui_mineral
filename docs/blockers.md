# Blockers

Gaps that need a change outside this repository.

| Area | State | Blocked on | Unblocks when |
|---|---|---|---|
| Bidi text | egui shapes text (harfrust) but has no bidi reordering: mixed LTR/RTL runs render in logical order. The `TextEdit` caret is off in RTL. Layout mirroring (`I18n::direction`) works. | egui: [#1016](https://github.com/emilk/egui/issues/1016), draft [#8577](https://github.com/emilk/egui/pull/8577) (unicode-bidi), [#8576](https://github.com/emilk/egui/issues/8576) / [#8698](https://github.com/emilk/egui/pull/8698) (caret). | Merged upstream and released. |
| Native file dialogs | rfd 0.18 runs each xdg-portal dialog and file read on its own detached thread. Dropping the future does not close the dialog. These threads have no owner. | rfd: cancellable dialogs with owned workers. | rfd exposes cancellation, `NativePlatform` drops the dialog with the future. |
| Percent, currency, units, compact numbers, relative time | Not in `LocaleFormat`, percent text comes from the `mineral-percent` catalog message. | ICU4X ships these only in `icu_experimental` (unstable API). | Stabilized in ICU4X, add `LocaleFormat` methods. |
| Rounded clipping of arbitrary content | Carousel items render truly rounded only for images (`show_images`). Other content gets corner masks painted in the background colour. | egui clips to rectangles only, no render-to-texture or stencil clip. | egui gains shape clipping or offscreen rendering. |
| Crate README links | `just readme` generates `crates/*/README.md` from the crate docs with cargo-rdme `--intralinks-strip-links`: intra-doc links render as code, not links. | rustdoc: resolving intra-doc links needs the unstable JSON backend ([#76578](https://github.com/rust-lang/rust/issues/76578)) on a nightly; cargo-rdme pins one older than the MSRV. | rustdoc JSON is stable, drop `--intralinks-strip-links`. |
| Duplicate zbus | `notify-rust` 4.19 uses zbus 6, `accesskit_unix` 0.24 (via eframe) zbus 5, both versions would link (~1.3 MB). `notify-rust` is held to `~4.18` (zbus 5). | accesskit: `accesskit_unix` on zbus 6. | eframe ships an accesskit on zbus 6, unpin `notify-rust`. |
| Doubled X11 wheel steps | Under xdotool/Xvfb one wheel notch steps value widgets twice. winit 0.30.13 X11 maps `XI_ButtonPress` and `XI_ButtonRelease` to the same handler (`event_processor.rs` 218) and emits `MouseWheel` for buttons 4-7 on both (1083). Real mice are unaffected: their button events carry `XIPointerEmulated` and are dropped (1063), scrolling arrives as XI2 valuator motion. No dedupe in mineral: a press/release pair is indistinguishable from two notches by then. | winit: emit wheel buttons on press only. | A winit release with the fix reaches eframe. |
| Hot-patch relink | `dx serve --hotpatch` fails after the first build with "Missing linker args for fat link", and `r` relinks stale object files. dioxus-cli 0.7.10 forces the app relink it captures linker args from by deleting `target/<triple>/<profile>/.fingerprint/<crate>-<hash>` (`request.rs` 1213, 3081); cargo 1.100 keeps fingerprints in `build/<crate>/<hash>/fingerprint`, so nothing relinks. `just hotpatch` touches the showcase `main.rs`; apps using `unstable-hotpatch` touch their own. | dioxus-cli: bust fingerprints in cargo's build-dir layout. | A dioxus-cli release with the fix; drop the `touch`. |
| Hot-patch shortcut hints | `just hotpatch` passes `--interactive false` (no `r` rebuild, see Hot-patch relink), but dioxus-cli 0.7.10 still prints the keyboard shortcut hints (`serve/mod.rs` 54-58) regardless of the flag. Cosmetic: the keys do nothing. | dioxus-cli: print the hints only in interactive mode. | A dioxus-cli release with the fix. |
| Scroll relay target | `PanClaim` hands declined pans and the coast to scroll areas through egui's pass-global scroll delta, queued from the owner widget's `Ui`: the first area to end after it takes the delta. A vertical scroll area nested in the page after the pannable, or any area when the pannable is culled mid-fling (root `Ui` fallback), can take it instead of the nearest ancestor. | egui 0.37: `scroll_area::State::offset` is private with no setter, so a delta cannot be addressed to one area by id. | egui exposes a per-id scroll delta or offset setter; relay to the recorded ancestor id. |
| Tabular figures | OpenType `tnum` cannot be requested. `kit::text::tabular_figures` pads each ASCII digit to the widest digit's advance instead (`StatusItem::tabular_figures`, Material `NumberField::tabular_figures`); the figures keep their proportional shapes and the focused `TextEdit` its shaped digits. | epaint 0.37: `shape_text` shapes with `harfrust::ShapeOptions::new()` (`text/text_layout.rs` 1605) and `TextFormat` has no feature field. | epaint exposes OpenType features per `TextFormat`; replace the padding with `tnum`. |
